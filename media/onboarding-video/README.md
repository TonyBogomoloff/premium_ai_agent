# Эмодзи-студия — знакомство за 30 секунд

Remotion 4.0.538, 720 × 1280, 30 fps, H.264/yuv420p, без звука.
Референс: Your Secret Agent v4 из соседнего проекта. Сохранены пропорции
телефона 9:20, крупные заголовки, тёмная палитра и пояснения вне телефона.
Переписка постановочная; мини-приложение воспроизведено по текущему index.html
и стилям проекта. Это иллюстрация возможностей, не запись реальной отправки.

| Время | Сцена |
| --- | --- |
| 0–3 | Добавь эмоций в переписку |
| 3–12 | Набор сообщения, анимированный эмодзи, жирный текст, отправка |
| 12–19 | Выбор стикера из Hot Cherry и отправка |
| 19–26 | Фото с подписью и эмодзи |
| 26–30 | Пиши ярче. Оставайся собой. @premium_emoji_app |

Использованы настоящие публичные анимации из каталога приложения, источники
перечислены в assets.json (URL относительно https://premium-emoji.korobkoff.com).
Это исходные анимации Telegram, не сгенерированные копии. Морской пейзаж и
звезда нарисованы SVG в исходнике. Шрифты и лицензии находятся в public/fonts.
Рендер не требует доступа к Telegram, ключей или отправки сообщений.
Сцены предполагают уже подключённый аккаунт и разрешённый личный диалог.

Установка и воспроизведение (Node.js 24+, pnpm):

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm render --browser-executable=/usr/bin/google-chrome
pnpm poster --browser-executable=/usr/bin/google-chrome
python3 validate.py
```

Результат рендера: ../../output/remotion/emoji-studio-v1-ru.mp4.
Публикуемая копия хранится в ../../public/promo/emoji-studio-v1-ru.mp4.
Ролик опубликован отдельным статическим файлом; автоматическая отправка
при /start в задачу создания ролика не входит.
