# Эмодзи-студия · @premium_emoji_app

Telegram Mini App: редактор с кастомными эмодзи, отдельная вкладка с обычными и Premium-стикерами, живой предпросмотр, фото и файлы с подписью, вырезание/копирование/вставка, поиск, собственные наборы, избранное, недавние и отправка от имени подключённого пользователя.

## Эмодзи и стикеры

В каталоге две вкладки: «Эмодзи» вставляет элементы в текст, «Стикеры» выбирает отдельное сообщение. После выбора стикера появляется предпросмотр и кнопка «Отправить стикер»; текст и прикреплённый файл остаются в черновике, в том числе после успешной отправки. Возврат во вкладку эмодзи отменяет выбор стикера. Стикером можно ответить на сообщение в доступном личном диалоге.

В каждой вкладке свои поиск, избранное и недавние. Добавленное в избранное отмечается закрашенной жёлтой звездой. В недавние стикер попадает после подтверждённой отправки. Ссылка для добавления стикеров — `https://t.me/addstickers/…`, для эмодзи — `https://t.me/addemoji/…`. Общий лимит — 24 личных набора; стартовые наборы в него не входят. В `premium_ai_agent.sticker_sets` можно указать дополнительные стартовые наборы.

Общий каталог содержит 236 наборов: 6080 стикеров, из них 581 с Premium-эффектом. 21 октября 2026 года через `getStickerSet` проверены 323 публичных набора; в подборку включены все найденные обычные наборы с непустым `premium_animation`. Источники: официальный канал [Premium Stickers](https://t.me/PremiumStickers/1), [Trending Stickers](https://t.me/s/TrendingStickers) и [Stickers](https://t.me/s/stickersnew). Это проверенная подборка, а не полный перечень всех наборов Telegram. Такие стикеры помечены ★ и доступны через фильтр «Только Premium». Каталог проигрывает основную анимацию TGS/WebM или показывает статический WebP; полноэкранный Premium-эффект воспроизводит клиент Telegram. Отправка использует исходный `file_id` через `sendSticker`, включая `business_connection_id` для личного диалога. Если в ответе Telegram отсутствует ожидаемый Premium-эффект или привязка к ответу, приложение предупреждает без повторной отправки. Наличие эффекта в API-ответе не доказывает его визуальное воспроизведение у получателя.

Изображения стикеров, как и эмодзи, проксируются и кешируются сервером. Telegram file_id и токен не передаются в каталог браузера. Добавленные наборы доступны для отправки только их владельцу; стартовые доступны всем. Публичные URL изображений не являются приватным хранилищем.

## Запуск

Требуется Node.js 24+. Фронтенд собирается Vite; сервер использует HTTP, SQLite и fetch из Node.js без внешних серверных зависимостей.

```sh
pnpm install
cp config.example.json config.json
# Укажи bot_token_premium_emoji_app либо используй PREMIUM_CONFIG с путём к существующему JSON.
./run.sh build
./run.sh start
```

Открой http://127.0.0.1:8787. В обычном браузере работает предпросмотр редактора, отправка выключена. Telegram передаёт подписанные initData при запуске мини-эпа: сервер проверяет подпись, срок действия и владельца подключения перед отправкой.

Для разработки: сервер на 8787 и `./run.sh dev` в другом терминале. Для проверок: `./run.sh test` и `./run.sh check`. Команда check читает только метаданные бота, webhook и меню.

## Подключение Telegram

1. В BotFather включи Business Mode у @premium_emoji_app, чтобы он мог быть секретарём.
2. Размести сборку и сервер на HTTPS-адресе. Укажи его в `PREMIUM_PUBLIC_URL` или `premium_ai_agent.public_url`.
3. Выполни `./run.sh setup`: команда настраивает кнопку меню и команды. Она не меняет webhook и не рассылает сообщения.
4. Запусти один экземпляр сервера с polling. Существующий webhook не удаляется: при его наличии polling отказывается запускаться.
5. Пользователь запускает бота, подключает секретаря к своему аккаунту и выбирает разрешённые чаты. Затем открывает редактор через меню.

Настройки можно хранить в общем config.json в секции `premium_ai_agent`, сам токен читается только из `bot_token_premium_emoji_app`. Переменные окружения: `PREMIUM_CONFIG`, `PREMIUM_PUBLIC_URL`, `PREMIUM_HOST`, `PREMIUM_PORT`, `PREMIUM_DATA_DIR`, `PREMIUM_POLLING=0`. Секретный конфиг нельзя помещать в dist или Git. Файлы пользовательских systemd-сервисов лежат в deploy; перед установкой проверь путь к Node.js и заполни .env с HTTPS-адресом. БД и кеш разделены по bot_id внутри каталога данных, поэтому смена бота не смешивает подключения и Telegram file_id.

Адрес размещения: https://premium-emoji.korobkoff.com. На my-server используется отдельный локально управляемый Cloudflare Tunnel и Node.js 24.22.0 в `.runtime`, без замены системного Node.js. Управление: `systemctl --user status premium-emoji-agent premium-emoji-tunnel`. Конфиг с токеном читается из `/home/tony/Desktop/_code/config.json`.

## Данные и доставка

- Кнопки «Копировать» и «Вырезать» сохраняют выделение с оформлением и премиум-эмодзи во внутреннем буфере до перезагрузки/закрытия редактора. Одновременно выполняется попытка записи в системный буфер; отказ не мешает внутренней вставке. Кнопка «Вставить» предпочитает внутренний буфер. Для вставки из другого приложения используй системное меню поля.

- Черновик, недавние и избранное хранятся в localStorage отдельно для каждого Telegram user_id. Для отправки содержимое передаётся серверу и Telegram; текст не пишется в лог. После отправки он входит в историю выбранного личного диалога.
- Сервер сохраняет подключения, имена/идентификаторы доступных получателей, выбранные наборы и метаданные отправок. В каждом личном диалоге сохраняются последние 100 доступных боту входящих и исходящих сообщений: текст, подпись, оформление, время, ссылка на ответ и метаданные вложения. Данные находятся в серверной SQLite, доступ к истории требует подписи Telegram, совпадения владельца и активного подключения. Полные медиафайлы для истории не архивируются; миниатюры загружаются через авторизованный серверный запрос без раскрытия токена или Telegram file_id.
- Список чатов формируется из новых business_message и выбора пользователя. Старую переписку и весь список контактов Bot API не загружает. Выбор контакта использует requestChat / savePreparedKeyboardButton (Telegram Bot API 9.6+); для старых клиентов остаётся список уже известных чатов.
- Перед отправкой сервер повторно проверяет текущее подключение и право can_reply. Окончательный доступ к конкретному чату проверяет Telegram. Никакой автоматической отправки от имени бота вместо пользователя нет.
- Получатель выбирается один, в верхней части экрана. Для личных диалогов под ним показывается история и кнопки «Ответить». История обновляется раз в 6 секунд только в открытом приложении, сохраняет положение прокрутки при чтении старых сообщений и учитывает правки/удаления из Telegram. Сбор начинается после установки обновления: Bot API не предоставляет загрузку старой переписки. Удалённое сообщение заменяется отметкой без сохранения его текста.
- Reply относится только к сообщению в выбранном диалоге; удалённое или вытесненное из последних 100 сообщение выбрать для ответа нельзя. Telegram может убрать привязку Business-ответа, если оригинал исчез во время отправки: в этом случае интерфейс сообщает об этом и не повторяет отправку.
- Идентификатор отправки защищает от дублей. После сетевой неопределённости повторная отправка блокируется, пока пользователь не проверит чат. После перезапуска незавершённые отправки также остаются неопределёнными.
- После принятой отправки сервер сверяет ID и позиции custom_emoji с ответом Telegram. Если оформление потерялось, редактор сообщает об этом, не повторяя отправку. В метаданных сохраняются только количества запрошенных и подтверждённых эмодзи; старые отправки без этих данных нельзя проверить задним числом.
- Emoji assets проксируются и кешируются сервером: URL с токеном Telegram не попадает в браузер. Анимации TGS воспроизводятся Lottie, WebM — видео; при reduced motion используются миниатюры.
- Вложение: одно фото (JPEG/PNG/WebP, до 10 МБ), видео с плеером (MP4, до 50 МБ) или файл (до 50 МБ). При вложении текст отправляется подписью до 1024 единиц UTF-16, включая оформление и кастомные эмодзи. Сервер передаёт файл через multipart в Telegram, не сохраняет его на диск; одновременно принимает не более двух загрузок, по одной на пользователя. Само вложение сохраняется в IndexedDB на устройстве отдельно для каждого пользователя и восстанавливается после закрытия приложения. После успешной отправки или удаления локальная копия удаляется. При отказе хранилища или очистке данных браузером интерфейс сообщает, что файл нужно выбрать заново; между устройствами вложения не синхронизируются.
- Буфер обмена использует системные разрешения браузера; при отказе кнопка объясняет, как воспользоваться обычным меню выделения. HTML-копирование сохраняет оформление и custom emoji внутри редактора, сторонние приложения могут их не поддерживать.
- Ограничение редактора без вложения: 4096 единиц UTF-16 и 100 кастомных эмодзи. Entities формируются на сервере, корректно учитывают составные эмодзи и форматирование.

## Проверка перед публикацией

`./run.sh test` покрывает подпись Telegram, изоляцию пользователей, Unicode, повторную/неопределённую отправку, отзыв прав и выбор контакта. Браузерная проверка использует подменённые Telegram API, не отправляет сообщения реальным людям. Проверка интерфейса и успешная сборка сами по себе не доказывают доставку с реального аккаунта.
